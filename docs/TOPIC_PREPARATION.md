# Topic Preparation Guide for Members

Use this workflow before adding a topic, prompt, or demo to EduGenie.

## 1. Define the learner

Write the audience, current level, goal, and expected time. Example: “A beginner who wants to explain photosynthesis in two minutes.”

## 2. Collect trustworthy source material

Use official documentation, textbooks, university material, or primary sources. Record the source name, URL, date checked, and the claim it supports.

## 3. Reduce the topic to a learning spine

Prepare: definition, prerequisites, three to five key ideas, one example, common misconception, and a short practice question.

## 4. Write a safe prompt

State the audience, requested format, length, and uncertainty behavior. Never place API keys, private student data, or confidential material in prompts.

## 5. Test the topic

Run the same topic through Ask, Explain, Summary, Quiz, and Learning path. Check factual accuracy, readability, JSON validity for quizzes, and whether the answer matches the learner level.

## 6. Review before sharing

A member other than the author should verify facts and examples. Mark content that needs expert review. AI output is a draft and must not be treated as an authority without checking.
