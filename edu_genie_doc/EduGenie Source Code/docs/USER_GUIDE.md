# User Guide

## Choose a tool

Use **Ask** for a direct question, **Explain** for a beginner-friendly concept breakdown, **Summarize** for long notes, **Quiz** for three practice questions, and **Learning path** for a sequence from beginner to advanced.

## Submit a request

Enter a question, topic, or passage and select the action button. The response appears below the form. Quiz answers can be checked one at a time; the app shows whether the choice matches the generated answer.

## Good inputs

Use specific prompts such as “Explain binary search with a small sorted-list example” instead of “binary search”. For summaries, include the complete passage and identify the intended reading level.

## Responsible use

Review AI-generated content against a trusted source. Do not use EduGenie as a replacement for a teacher, medical professional, legal adviser, or exam policy. Do not paste personal, sensitive, or confidential information.

## Status indicator

“Gemini connected” means the configured API is active. “Demo mode” means the interface is running with local sample responses until a Gemini key is added.
